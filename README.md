# 词选｜初中英语四选一识义训练

一个面向初中生的轻量英语词义训练网站。每题展示一个英文单词和四个中文释义，帮助学生建立“看到单词即可识别含义”的阅读基础。

## 主要功能

- 1970 个初中英语词条，来源于本地整理的“初中乱序”词表
- 每个新单词默认自动播放美式发音
- 四选一答题，支持键盘数字键 `1`—`4`
- 答对后快速进入下一题
- 答错后显示正确答案并停留 3 秒
- 错词约 5 题后再次出现
- 独立错题本；连续答对两次后移出待巩固列表
- 每轮支持 10、20 或 30 题
- 使用浏览器 `localStorage` 保存学习记录，无需注册或后端服务

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

生产构建与数据校验：

```bash
npm run build
npm test
```

## 项目结构

- `app/page.tsx`：练习流程、发音、选项生成和错题逻辑
- `app/globals.css`：页面样式与响应式布局
- `public/words.json`：网站直接使用的结构化词库
- `public/og-card.png`：社交分享预览图

## 发音说明

发音使用浏览器 Web Speech API，优先选择 `en-US` 语音，默认语速为 `0.85`。具体音色取决于设备和浏览器中已安装的语音。

## 数据隐私

答题记录仅保存在当前浏览器中，不会上传到服务器。清除浏览器站点数据后，学习记录也会被清除。
